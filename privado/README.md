# Arquivo da equipe · no GitHub privado, fora do site

Esta pasta é versionada junto com o projeto. Depois de commit e push, fica armazenada no **repositório privado do GitHub** e acompanha um clone completo. Ela não é copiada para a pasta `dist/` publicada na Vercel.

O nome `privado/` apenas identifica materiais de equipe. A proteção de acesso vem da visibilidade **Private** do repositório; não mudar para Public enquanto este conteúdo estiver incluído.

| Área | Conteúdo |
| --- | --- |
| [equipe/GUIA_DA_EQUIPE.md](equipe/GUIA_DA_EQUIPE.md) | Preparação, credenciais de interface, narrativa, respostas, horários, pistas e reinício. |
| [contexto/CONTINUIDADE_COMPLETA.md](contexto/CONTINUIDADE_COMPLETA.md) | Orientação para continuar o projeto com todas as fontes. |
| `fontes/` | Retratos, identidade visual, matrizes, dados internos e scripts históricos, incluindo ZIPs de produção. |
| `historico/` | Documentação e README anteriores, apresentação e manuais substituídos. |
| `verificacao/` | Relatórios e capturas da conferência da entrega, preservados como evidência. |
| `INVENTARIO_ORIGEM.json` | Correspondência e hashes entre originais e divisões da entrega. |

Os manuais arquivados em `historico/` registram decisões anteriores, inclusive a antiga exclusão desta pasta do Git. A regra vigente é a deste README e da documentação principal: incluir as fontes na nuvem privada, publicar apenas o sistema.

O gabarito também existe no JavaScript usado pelos jogadores. As senhas de interface não são autenticação de servidor; repositório privado não torna secreto o código entregue no navegador.
