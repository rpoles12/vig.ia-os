# Fontes

| Arquivo | Uso no gerador |
| --- | --- |
| `SpaceGrotesk-Bold.ttf` | Registrada como `Space`; títulos e destaques. |
| `IBMPlexMono-Regular.ttf` | Registrada como `Mono`; textos, legendas e rodapés. |

O PDF incorpora as fontes a partir destes arquivos; não é necessário instalá-las no Windows para gerar a apresentação. Não há arquivos de licença das fontes nesta pasta; consulte as licenças de origem antes de redistribuí-las separadamente.
