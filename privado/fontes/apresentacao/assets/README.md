# Recursos da apresentação

Arquivos de entrada usados por `producao/montar_apresentacao.py`.

| Pasta | Função |
| --- | --- |
| [fontes/](fontes/README.md) | Tipografia dos títulos e dos textos. |
| [imagens/](imagens/README.md) | Ilustrações, capturas, documentos e marca. |

Mantenha estes arquivos junto do projeto para permitir a geração do PDF em outro computador. O gerador lê as cópias locais; não busca recursos no pacote externo.
